## 一、核心业务流程

### 1.1 积分充值与消费流程

```
企业A充值 ¥10,000
    ↓
换算积分: 10,000 × 汇率 = 100,000 积分
    ↓
存入组织积分账户
    ↓
用户创建任务
    ↓
系统计算消耗(按次/按Token)
    ↓
扣除积分(任务失败退回)
    ↓
达到预算上限 → 自动停服
```

### 1.2 产品价值

- **灵活计费**: 支持按次和按Token两种计费模式,满足不同业务需求
- **成本可控**: 月度/总预算管理,超预算自动停服,避免意外超支
- **透明可查**: 多维度消费报表,组织/项目/成员三级视图
- **差异化定价**: 支持组织级自定义价格和折扣配置

## 二、计费模式设计

### 2.1 双轨制计费

**按次计费模式**
- 适用场景: 图片生成、视频生成、语音合成等固定次数服务
- 计费单位: 次/张/个/秒/字符
- 示例定价:
  - 2K图片生成: 8积分/张 (¥0.80)
  - 4K图片生成: 12积分/张 (¥1.20)
  - 15秒视频生成: 15积分/个 (¥1.50)
  - TTS语音合成: 0.03积分/字符

**按Token计费模式**
- 适用场景: 文本生成、对话理解等Token计量服务
- 计费单位: 1K Token
- 示例定价:
  - Seedream 4.5 文本生成: 1积分/1K Token (¥0.10)
  - Seedream 4.5 对话理解: 0.8积分/1K Token (¥0.08)
- 区分输入输出: 输入Token和输出Token可设置不同系数

### 2.2 定价策略

**基础定价**
- 平台统一配置各模型的标准价格
- 支持多供应商接入(volcano/openai/sora/custom)

**成本价与销售价分离**
- 支持上游成本价(按Token/按次)与下游销售价独立配置
- 自动计算实际利润率,基于历史数据优化定价
- 智能价格建议,确保目标利润率
- 利润率监控告警,及时识别亏损风险

**组织级定价**
- 支持为不同组织设置自定义价格
- 支持额外折扣率配置
- 支持有效期管理

**阶梯优惠**
- 根据使用量提供阶梯折扣
- 达到阈值自动触发返利
- 鼓励大客户批量消费

**资源包**
- 预付费资源包模式
- 更优惠的积分价格
- 固定有效期管理

### 2.3 特殊场景处理: 上游按Token计费,下游按次收费

**业务场景**
部分上游API(如火山引擎视频生成1.5Pro)按Token计费,但实际Token消耗会根据生成长度、复杂度等因素波动。为简化用户体验,我们对客采用固定价格按次收费。

**示例: 火山视频1.5Pro**

| 维度 | 计费方式 | 说明 |
|------|----------|------|
| **上游成本** | 按Token计费 | 每次生成长度不同,Token消耗不同,成本波动 |
| **下游对客** | 按次固定价格 | 15积分/次(¥1.50),无论Token多少 |
| **平均成本** | 基于历史统计 | 假设平均每次消耗12.5K Token,成本约¥1.00(10积分) |
| **实际利润率** | 动态计算 | (15-10)/15 = 33.3% |

**管理后台功能**

在管理后台新增"成本与利润管理"模块,支持:

1. **双重定价配置**
   - 独立设置上游成本价(按Token: ¥0.08/1K Token)
   - 独立设置对客销售价(按次: 15积分/次)

2. **利润率实时监控**
   - 基于近30天数据计算实际利润率
   - 显示利润率分布(高/中/低)
   - 识别亏损订单

3. **智能价格建议**
   - 根据平均Token消耗计算建议价格
   - 确保目标利润率(如50%)
   - 一键采纳建议价格

4. **分级定价(可选)**
   - 对于Token消耗波动大的模型,支持分级定价
   - 示例: 短视频(≤5秒)8积分,标准视频(5-10秒)15积分,长视频(>10秒)25积分

**实施建议**
- 初期: 采用成本价与销售价分离模式,快速上线
- 中期: 增加价格监控模块,定期分析优化
- 后期: 对高波动模型采用分级定价,精细化运营

## 三、积分体系设计

### 3.1 积分汇率

- **换算比例**: 1元 = 10积分
- **积分价值**: 1积分 = ¥0.10
- **充值赠送**: 根据充值金额阶梯赠送
  - 充值≥¥1,000: 额外赠送10%
  - 充值≥¥5,000: 额外赠送12%
  - 充值≥¥10,000: 额外赠送15%

### 3.2 积分类别

**可用积分**
- 当前可使用的积分余额
- 充值后立即到账
- 消费时优先扣除

**冻结积分**
- 任务进行中暂时冻结的积分
- 任务完成后解冻
- 防止并发消费超额

**历史汇总**
- 历史充值总额
- 历史消费总额
- 帮助了解消费趋势

### 3.3 充值方式

- **支付宝**: 在线扫码支付
- **微信支付**: 在线扫码支付
- **银行转账**: 人工充值,需上传凭证
- **系统赠送**: 管理员后台手动充值

## 四、预算管理机制

### 4.1 预算类型

**月度预算**
- 按自然月管理预算
- 月初自动重置
- 适合周期性费用控制

**总预算**
- 累计消费上限
- 不自动重置
- 适合总体成本控制

### 4.2 告警机制

**80%告警**
- 预算使用达到80%时触发
- 通知组织管理员
- 继续服务

**100%停服**
- 预算使用达到100%时触发
- 自动暂停服务
- 充值后自动恢复

### 4.3 告警通知

- **站内通知**: 系统消息推送
- **邮件通知**: 发送至管理员邮箱
- **短信通知**: 发送至管理员手机(可选)
- **通知内容**: 预算使用情况、超期提醒、充值引导

## 五、产品页面设计

### 5.1 页面架构

本系统设计了**四个视角**的账单页面,满足不同角色的使用需求:

| 页面 | 视角 | 主要功能 |
|------|------|----------|
| **我的账单** | 子账号/个人视角 | 查看个人消费、积分余额、项目分布 |
| **企业账单** | 企业管理员视角 | 查看全组织消费、成员排行、任务类型分布 |
| **项目费用详情** | 项目维度视角 | 查看项目内成员消费、模型使用分布 |
| **管理后台** | 平台经营者视角 | 查看全平台收入、成本、利润、TOP客户 |

### 5.2 我的账单(个人视角)

**目标用户**: 企业子账号/普通成员

**核心功能**:

1. **积分余额卡片**
   - 可用积分: 实时显示
   - 本月消耗: 月度累计消费
   - 月度预算: 预算上限
   - 预算进度条: 可视化展示使用百分比
   - 等值人民币: 积分对应金额

2. **消费趋势图表**
   - 近7天/30天消费趋势折线图
   - 支持时间范围切换
   - 渐变填充效果,数据可视化更美观

3. **各项目消费分布**
   - 项目维度费用排行
   - 显示消费积分和占比
   - 支持点击跳转到项目详情

4. **消费明细表格**
   - 时间筛选: 今天/7天/30天
   - 计费模式筛选: 全部/按次/Token
   - 项目筛选: 下拉选择
   - 分页功能: 每页10/20/50条
   - 导出CSV功能

5. **充值中心**
   - 充值包选择: 1000元/5000元/10000元/自定义
   - 赠送积分展示
   - 支付方式选择
   - 充值记录查询

**使用场景**:
- 成员日常查看个人积分余额
- 了解个人消费趋势
- 查看各项目消费明细
- 充值积分(如有权限)

### 5.3 企业账单(管理员视角)

**目标用户**: 企业管理员/组织负责人

**核心功能**:

1. **组织积分余额卡片**
   - 可用积分: 全组织余额
   - 本月消耗: 全组织月度消费
   - 月度预算: 组织预算上限
   - 等值人民币: 积分对应金额

2. **组织消费趋势图**
   - 累计消费趋势(近7天/30天/全年)
   - 支持自定义时间范围
   - 平滑曲线 + 渐变填充

3. **成员消费分布**
   - 饼图展示各成员消费占比
   - TOP 10成员消费排行
   - 支持时间范围筛选
   - 点击成员可查看详情

4. **任务类型消费分布**
   - 剧本创作、图片生成、视频生成、配音
   - 饼图展示 + 百分比
   - 支持时间范围筛选

5. **组织消费明细表格**
   - 显示全组织所有消费记录
   - 支持项目筛选
   - 支持成员筛选
   - 支持时间筛选
   - 分页 + 导出CSV

6. **预算管理**
   - 设置月度预算
   - 设置总预算
   - 查看预算告警记录

**使用场景**:
- 管理员监控全组织费用
- 了解成员消费分布
- 分析任务类型占比
- 设置和管理预算
- 导出组织账单

### 5.4 项目费用详情(项目维度)

**目标用户**: 项目负责人/企业管理员

**核心功能**:

1. **项目信息卡片**
   - 项目名称
   - 本月总消费
   - 任务数
   - 参与成员数

2. **成员费用分布**
   - 成员维度费用排行
   - 显示排名、头像、姓名、积分、占比
   - Top 3成员特殊标识

3. **模型使用分布**
   - Seedream 4.5, Seedance 1.5, 豆包TTS, Sora2
   - 饼图展示占比
   - 支持点击查看详情

4. **详细记录表格**
   - 显示该项目下所有消费记录
   - 成员筛选
   - 模型筛选
   - 时间范围筛选
   - 分页功能
   - 支持导出

**使用场景**:
- 项目负责人监控项目费用
- 了解成员贡献度
- 分析模型使用偏好
- 项目成本核算

### 5.5 管理后台(平台视角)

**目标用户**: 平台经营者/超级管理员

**核心功能**:

1. **核心指标卡片**
   - 总收入: 平台累计收入
   - 总成本: 模型调用成本
   - 总利润: 收入-成本
   - 利润率: 利润/收入
   - 环比增长率

2. **收入/成本/利润趋势图**
   - 三色折线图展示
   - 绿色: 收入
   - 橙色: 成本
   - 蓝色: 利润
   - 支持时间范围切换(7天/30天/90天/6个月/1年)

3. **各模型消耗占比**
   - Seedream 4.5, Seedance 1.5, 豆包TTS, Sora2
   - 饼图展示占比
   - 支持时间范围筛选

4. **TOP 50消费组织**
   - 排名、企业名称、用户数、消费积分、等值金额、充值金额、余额
   - 支持时间范围筛选(today/week/month/quarter/year)
   - 分页功能
   - 前3名特殊标识

5. **定价管理**
   - 查看所有模型定价配置
   - 新增/编辑/删除定价
   - 设置组织级自定义价格
   - 配置折扣和阶梯优惠

6. **充值管理**
   - 查看所有充值记录
   - 审核银行转账充值
   - 手动赠送积分

7. **预算管理**
   - 查看所有组织预算设置
   - 为组织设置预算上限
   - 查看预算告警记录

8. **数据统计功能**
   - 时间范围筛选
   - 实时更新图表
   - 数据导出功能

**使用场景**:
- 平台经营者监控整体经营状况
- 分析收入成本利润趋势
- 了解客户消费排行
- 配置产品定价策略
- 管理组织预算

### 5.6 UI/UX特点

- **响应式设计**: 支持桌面端和移动端
- **主题切换**: 支持亮色/暗色主题
- **实时更新**: 数据实时刷新
- **交互友好**: 流畅的动画效果
- **数据可视化**: 图表直观展示
- **操作便捷**: 筛选、分页、导出功能完善
