## 🎨 设计规范

本项目严格遵循 [前端规范.md](../前端规范.md) 的设计规范：

### 技术栈
- **Tailwind CSS** - 实用工具优先的 CSS 框架
- **DaisyUI v4.6.0** - 基于 Tailwind 的组件库
- **RemixIcon v3.5.0** - 图标库
- **Inter** - 字体家族

### 品牌色
- **主品牌色（Kline）**: `#002FA7`
- **渐变文本**: `linear-gradient(135deg, #002FA7 0%, #2560FF 50%, #4D7CFF 100%)`

### 响应式断点
- `default`: < 640px (移动设备)
- `md`: ≥ 768px (平板设备)
- `lg`: ≥ 1024px (小屏笔记本)
- `xl`: ≥ 1280px (桌面设备)

## 🚀 快速开始

### 1. 直接打开
直接在浏览器中打开 `index.html` 文件即可查看。

### 2. 使用本地服务器（推荐）
```bash
# 使用 Python 3
cd project-detail
python -m http.server 8000

# 或使用 Node.js
npx serve

# 然后在浏览器中访问
# http://localhost:8000
```

## ⌨️ 快捷键

- **Ctrl/Cmd + K**: 快速搜索（当前标签页）
- **Ctrl/Cmd + N**: 新建项目（当前标签页）
- **ESC**: 关闭模态框

## 📝 主要功能说明

### 标签页切换
页面使用标签页式布局，可以在7个模块之间快速切换：
1. 剧本
2. 角色
3. 场景
4. 物品
5. 融合生图
6. 视频
7. 配音

### 搜索功能
每个标签页都有独立的搜索功能，可以快速过滤列表内容。

### 模态框
- 新增剧本
- 新增角色
- 新增视频
- 新增配音

### 主题切换
支持亮色/暗色主题切换，自动保存用户偏好到 localStorage。
